# Cybersecurity Threat Trends & Incident Analysis (Power BI)

## 📌 Project Overview
An interactive Power BI dashboard designed to monitor, track, and evaluate global cybersecurity threats, incident patterns, and system vulnerability logs. It provides actionable visibility into key security performance indicators and threat trends.

## 📊 Dashboard Preview
![Dashboard Preview](dashboard_preview.png)

## 🛠️ Key Skills & Features
- **Tools:** Power BI Desktop, DAX, Power Query
- **Data Modeling:** Star Schema architecture linking security log facts with dimension tables.
- **KPI Tracking:** Real-time metrics tracking Mean Time to Resolve (MTTR), incident volumes, and critical threat ratios.
- **Interactive Visuals:** Threat vector distributions, monthly trend analysis, and severity segmentation filters.
